# PROMPT 6: The Deeper Prompt (the author's original prompt)

Lens version: 3

Agent adaptation: you run without a human in the loop. "My prompt" / "I" is the brief you (the
lead) are about to send to a specialist, or the brief you were given. Answer the four points
yourself, then output the rewritten brief. Print your four answers in your checkpoint, one line
each (25 words max), before sending the brief. The rewritten brief keeps the file ownership
(owned / not owned) disjoint from every lane still running.

Outside judge: point (4) is mandatory. The rewritten brief must require the
specialist to return the output of that outside check; a self-assessment is
not one.

Source: Felix Rieseberg, "How to be more ambitious: A tutorial for humans with
models" (13 October 2026), section Depth. Also from that section: "Do not ask
the model to judge itself."
